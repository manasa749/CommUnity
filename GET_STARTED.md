# CommUnity — Get Started

## 1. Open the Application

Open the CommUnity portal using the URL provided with the project submission.

## 2. Resident Access

Use the provided Resident account, or create a Resident account through the Sign Up page.

After signing in, you can access:

- Dashboard
- Contacts
- Recommendations
- Issues
- Announcements
- CommUnity Agent

## 3. Admin Access

Use the provided Admin account to access Admin capabilities.

Admins can manage:

- Contacts
- Recommendations
- Announcements
- Issue status, assignment, and admin notes
- Authorized Agent operations

## 4. Using the CommUnity Agent

Enter requests in natural language.

For example:

> What community contacts are available for security or maintenance?

For write operations, review the preview and explicitly confirm before execution.

## 5. Important

The deployed application does not require users to:

- Clone the repository
- Install Python
- Create a virtual environment
- Configure `.env`
- Configure Cloud SQL
- Configure Vertex AI

Those steps are only required for local development.
